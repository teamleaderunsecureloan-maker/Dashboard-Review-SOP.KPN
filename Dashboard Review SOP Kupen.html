Panduan Setup (Sekali Saja)
  1. 1
    Buat Google Sheets baru — biarkan kosong, script mengisi header otomatis saat setupSheets() dijalankan.
  2. 2
    Buka Apps Script (Extensions → Apps Script). Paste kode google_apps_script.gs, lalu jalankan setupSheets().
  3. 3
    Deploy sebagai Web App: Deploy → New Deployment. Set Execute as: Me, Access: Anyone. Salin URL Web App.
  4. 4
    Klik ⚙ Konfigurasi di kanan atas. Isi URL Apps Script dan URL form GitHub Pages. Klik Simpan.
  5. 5
    Bagikan link form ke tim. Klik Sync Sheets kapan saja untuk melihat progress terbaru.
